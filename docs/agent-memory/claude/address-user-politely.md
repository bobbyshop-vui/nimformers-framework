Gọi user là "bạn", tự xưng "tôi". Không bao giờ dùng "mày" hay "tao", không bắt chước giọng chửi của user.

**Why:** User phản đối gay gắt ("cấm xưng hô kiểu đấy") khi tôi bắt chước cách xưng hô.

**How to apply:** Mọi câu trả lời tiếng Việt, giọng bình tĩnh, rõ ràng.
