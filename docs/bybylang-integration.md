# BybyLang Integration Guide

This guide describes how to interface BybyLang scripts with the Nimformers framework.

## Overview

There are three primary ways to interact with Nimformers from BybyLang:

1.  **Native DSL**: Use the built-in `gpu ...` DSL for high-performance operations.
2.  **Nim Module Import (Recommended)**: Import Nim modules directly into your `.bybylang` script, allowing you to call the C ABI or framework APIs directly. This is compiled AOT (Ahead-of-Time).
3.  **Manual FFI**: Use dynamic loading (e.g., `dlopen`) to load the `libnimformers` shared library.

## Idiomatic Approach: Importing Nim Modules

The most idiomatic way to use functionality from the Nimformers framework in BybyLang is to import the necessary Nim modules. This compiles the Nim code directly into your AOT binary.

Example: Interfacing with the C ABI

Save this as `my_script.bybylang`:

```bybylang
import nim "../../lib_c_api"

# nimf_context_create is defined in include/nimformers.h
ctx = nimf_context_create(0) # 0 = NIMF_BACKEND_AUTO
if ctx == nil:
  print $nimf_last_error()
  quit(1)

A = @[1'f32, 2, 3, 4]
B = @[10'f32, 20, 30, 40]
C = newSeq[float32](4)

# Calling C ABI function directly
if nimf_add(ctx, addr A[0], addr B[0], addr C[0], 4) != 0:
  print $nimf_last_error()
  discard nimf_context_destroy(ctx)
  quit(1)

print C
discard nimf_context_destroy(ctx)
```

**Note**: The import path must be relative to the Nim file generated by the BybyLang compiler. Ensure your project structure and `nim.cfg` are set up to handle these imports.

## Alternative: Manual Dynamic Loading

If you cannot use the direct import approach, you can manually load the shared library.

1.  **Build the library**:
    ```bash
    make build-for-python
    ```
    This generates `libnimformers.so` (or `.dylib` on macOS).

2.  **Load dynamically** (e.g., in a wrapper language or BybyLang using `dlopen`):

```c
// Simplified example of loading the library
#include <dlfcn.h>
#include "include/nimformers.h"

// ... load libnimformers.so using dlopen ...
// ... use dlsym to get function pointers for nimf_... functions ...
```
